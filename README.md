# ✨ The Dressing Room of Fashion ✨

A trendy outfit selection web app designed for Gen-Z and Gen-Alpha teens to discover their perfect style!

## 🌟 Features

- **8 Trendy Style Profiles**: Y2K Aesthetic, Dark Academia, Cottagecore, Streetwear, VSCO Girl, E-Girl/E-Boy, Minimalist, and Grunge
- **Complete Outfit Generation**: Tops, bottoms, shoes, and accessories
- **Mobile-First Design**: Responsive layout optimized for teens' preferred devices
- **Interactive UI**: Smooth animations and engaging visual design
- **Instant Outfit Updates**: Generate new looks with a single click

## 🎨 Style Profiles Included

### Y2K Aesthetic 🌈
Shimmery tops, low-rise jeans, platform shoes, and holographic accessories

### Dark Academia 📚
Cozy sweaters, pleated skirts, Doc Martens, and vintage accessories

### Cottagecore 🌻
Floral blouses, flowing skirts, canvas sneakers, and natural accessories

### Streetwear 🔥
Oversized hoodies, cargo pants, chunky sneakers, and bold accessories

### VSCO Girl 🌊
Vintage tees, mom jeans, Vans sneakers, and eco-friendly accessories

### E-Girl/E-Boy 🖤
Mesh tops, plaid skirts, platform boots, and edgy accessories

### Minimalist 🤍
Clean basics, neutral tones, simple shoes, and delicate accessories

### Grunge ⚡
Flannel shirts, ripped jeans, combat boots, and alternative accessories

## 🚀 Getting Started

### Prerequisites
- Python 3.x (for local development server)
- Modern web browser

### Running the App

1. Clone or download this repository
2. Open terminal in the project directory
3. Run the development server:
   ```bash
   python3 -m http.server 8000
   ```
4. Open your browser and navigate to `http://localhost:8000`

### Alternative Methods
- Open `index.html` directly in your browser
- Use VS Code Live Server extension
- Deploy to any static hosting service

## 📱 Usage

1. **Choose Your Vibe**: Select from 8 trendy style profiles
2. **Get Your Outfit**: View your personalized outfit recommendation
3. **Try New Looks**: Click "Try Another Look" for different options
4. **Switch Styles**: Go back to explore different aesthetics
